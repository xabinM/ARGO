# 🌍 ARGO - AR 기반 현장체험학습 플랫폼

## 📌 서비스 한줄 소개
**AR과 위치 기반 미션을 통한 몰입형 현장체험학습 플랫폼**

---

## 🚀 프로젝트 개요

**ARGO**는 교사와 학생이 함께 참여하는 **AR 기반 현장체험학습 플랫폼**입니다. 
교사는 반을 생성하고 학생들을 팀으로 구성하며, 학생들은 실제 현장에서 **AR 오브젝트**를 찾아 미션을 수행합니다. 
미션 성공 시 **랜덤 카드**를 획득하여 팀 간 **카드 배틀**을 통한 경쟁 요소까지 결합한 종합적인 교육 게임 플랫폼입니다.

---

## 🎯 핵심 기능

### 📚 **반 및 팀 관리 시스템**
- **교사**: 반 생성, 초대코드 발급, 학생 승인/거절
- **학생**: 초대코드로 반 참여 신청, 팀 배정
- **팀 시스템**: 교사가 직접 배정 또는 자동 랜덤 배정

### 🎯 **AR 기반 미션 수행**
- **위치 기반 미션**: GPS 좌표 기반 미션 스팟 설정
- **AR 오브젝트 탐색**: 안드로이드 카메라로 실제 공간에서 3D 오브젝트 발견
- **몰입형 상호작용**: ARCore 기반 터치, 제스처 인식
- **다양한 미션 타입**: 
  - QR 스캔 미션
  - AR 오브젝트 터치 미션
  - 사진 인증 미션  
  - 위치 기반 퀴즈 미션
  - 보물찾기 미션

### 🃏 **카드 수집 & 배틀 시스템**
- **랜덤 카드 보상**: 미션 성공 시 희귀도별 카드 획득
- **카드 속성**: 공격력, 방어력, 희귀도(일반/레어/에픽/전설)
- **팀 간 배틀**: 수집한 카드로 실시간 대전
- **배틀 매칭**: 팀 간 배틀 요청/수락 시스템

### 📊 **실시간 모니터링**
- **교사 대시보드**: 실시간 팀별 진행 현황 추적
- **지도 기반 현황**: 각 팀의 위치와 완료율 시각화
- **통계 및 리포트**: 미션별/팀별 상세 분석

## 🌟 프로젝트 특장점

### 1. **몰입형 현장 학습**
- GPS 기반 실제 위치 도달 필수
- AR 기술로 현실과 디지털 콘텐츠 융합
- 게임 요소로 학습 동기 극대화

### 2. **협력 기반 팀 활동**
- 팀원 간 협력으로 미션 수행
- 팀 대항 배틀로 건전한 경쟁 유도
- 소통과 협업 능력 개발

### 3. **교사 친화적 관리 도구**
- 직관적인 반/팀 관리 인터페이스
- 실시간 진행 상황 모니터링
- 자동화된 리포트 생성

### 4. **확장 가능한 콘텐츠**
- 다양한 현장에 적용 가능한 미션 시스템
- 교사가 직접 미션 스팟 추가 가능
- 미션 타입별 맞춤형 콘텐츠

## 🛠 기술 스택

### **Frontend**
- **Android**: Kotlin, ARCore
- **AR Rendering**: OpenGL ES, 3D 모델링
- **위치 서비스**: GPS, Google Maps API

### **Backend**
- **Framework**: Spring Boot, Spring Security
- **Database**: MySQL, Redis (캐싱)
- **API**: RESTful API, WebSocket (실시간)

### **AI & Data**
- **AI 모델**: Llama 3.2 Blossom (미션 생성)
- **데이터**: 문화재 공공데이터, RAG 시스템
- **ML**: 위치 기반 추천, 콘텐츠 자동 생성

### **Infrastructure**
- **Cloud**: AWS EC2, S3
- **Container**: Docker
- **CI/CD**: GitLab

## 📋 주요 API 엔드포인트

### 🏫 반 관리
- `POST /api/classes` - 반 생성
- `GET /api/classes/{classId}` - 반 상세 조회
- `POST /api/classes/join` - 반 참여 신청

### 👥 팀 관리  
- `POST /api/classes/{classId}/teams` - 팀 생성
- `POST /api/classes/{classId}/teams/{teamId}/assign` - 팀 배정
- `POST /api/classes/{classId}/teams/random-assign` - 랜덤 배정

### 🎯 미션 시스템
- `POST /api/classes/{classId}/missions/{spotId}/start` - 미션 시작
- `POST /api/missions/{missionId}/complete` - 미션 완료
- `GET /api/classes/{classId}/missions/overview` - 진행 현황

### ⚔️ 배틀 시스템
- `POST /api/teams/{teamId}/battle/request` - 배틀 요청
- `PUT /api/battle/requests/{requestId}/respond` - 배틀 응답
- `POST /api/battles/{battleId}/select-card` - 카드 선택

> 📖 **상세 API 명세**: [API 문서 링크](./api-spec.md)
